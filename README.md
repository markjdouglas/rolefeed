# RoleFeed

Finds operations leadership roles by querying public applicant tracking system (ATS)
endpoints for a curated list of employers, then filtering hard.

No scraping, no paid APIs, no LinkedIn. Four public endpoints, one employer list.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`source .venv/bin/activate` puts the virtual environment's Python first on your PATH,
so `python` means this project's Python with this project's packages. Run it in every
new terminal tab. `deactivate` undoes it.

## Use

Resolve where each employer's job board lives. Run this after editing `companies.yaml`.
Takes four or five minutes — it is deliberately slow to be polite to free endpoints.

```bash
python discover.py
```

Fetch and filter:

```bash
python fetch.py            # matching roles only
python fetch.py --all      # every role, to sanity-check the filter
python fetch.py --json     # also write data/jobs.json
```

If `fetch.py` returns nothing, run `--all` before assuming the code is broken. An empty
result usually means the filter is too tight, not that the fetch failed.

## Files

| File | Purpose |
|---|---|
| `companies.yaml` | The curated employer list. This is the actual product — edit it often. |
| `companies.resolved.yaml` | Generated by `discover.py`. Employer → ATS → verified token. |
| `ats.py` | One adapter per ATS. All four return the same dict shape. |
| `discover.py` | Probes candidate tokens against all four endpoints. |
| `fetch.py` | Pulls, dedupes, filters, prints. |
| `CLAUDE.md` | Standing brief for Claude Code. Read at the start of every session. |
| `SPEC.md` | What this is, what it deliberately is not, and why. |

## Fixing an unresolved employer

`discover.py` guesses board tokens from employer names, so many will miss. To fix one,
open that employer's careers page and read the URL:

| URL contains | ats | slug |
|---|---|---|
| `boards.greenhouse.io/acme` | `greenhouse` | `acme` |
| `jobs.lever.co/acme` | `lever` | `acme` |
| `jobs.ashbyhq.com/acme` | `ashby` | `acme` |
| `jobs.smartrecruiters.com/Acme` | `smartrecruiters` | `Acme` |

Then pin it in `companies.yaml`:

```yaml
- { name: Acme, slug: acme, sector: fintech, ats: greenhouse }
```

A pinned entry is verified rather than probed, so it costs one request instead of four.
