v0.4.1 current

21 September 2026
  • The checkerboard floor moved to the gutters. It ran across the whole page at 9% alpha on an 8-pixel grid, which is a highlight on a card edge but noise behind prose — the stats line and the section bands were hard to read. A fixed panel now paints the content column solid, so the tile survives only either side of it and reads as a frame. Below the 1180-pixel column there are no gutters, so on a phone it disappears entirely.
  • SmartRecruiters now pages. The adapter asked for 100 postings and never requested a second page, so Sixt, Delivery Hero and Grab each reported exactly 100 — the cap, not their real count. Roles were being lost silently. An employer landing precisely on a page boundary is the signature of un-paged collection.
  • The collection moved off the hour to 37 minutes past. Measured across 14 runs, an on-the-hour schedule fired 11 to 17 minutes late every single time, because 0 * * * * is the most common cron expression on GitHub and the shared scheduler queue is deepest then.
  • The goose performs every five seconds rather than seven.
  • Board discovery re-run across all 211 employers, resolving 62 (29%, up from 22%) and 3,918 open roles in 23.3 minutes. Teamtailor accounts for eight of them and, on its own, took enterprise reachability from 15% to 22%.
  • The product brief now carries the measured funnel, and a test of its own central claim. Splitting the 62 reachable employers by the kind of system they were reached through gives a monotonic gradient: 31% of enterprise employers came via Greenhouse, Lever or Ashby, against 80% of large, 89% of mid, 89% of scaleup and 100% of startup. Applicant tracking system adoption tracks company type, so this method's reach is inversely correlated with the employers it is aimed at. The hypothesis is downgraded from supported to weakly supported and restated around publishing surfaces rather than employers.
  • Roadmap resequenced, correcting an earlier call. The response to the enterprise gap was going to be careers-page structured data. The numbers say adding adapters is cheaper and better evidenced: probe Workable, Personio, Pinpoint, Applied, Eploy, Jobtrain, Tribepad and Hireserve first, and keep structured data for employers with no open endpoint under any system.
  • A product brief, and navigation that looks like navigation. The only route off the feed was the version number, which reads as a label rather than a control — nobody clicks a version number. Three raised tabs now sit under the wordmark, with a press state that pushes each into its own shadow.
  • Fixed a bug in the gutter panel before it shipped. The solid panel was a body::before at z-index: -1, which paints before the background of any in-flow unpositioned box — including body itself. The tile would have drawn straight back over the panel. The tile now sits on html, which paints first.
  • Job URLs are now scheme-checked, not just escaped. Escaping stops a value breaking out of an attribute; it does nothing about href="javascript:…", which needs no quotes or angle brackets to run script on this origin. Every job URL arrives from a third party's API, so only http and https are now allowed through.
  • Crawler exclusion added — a noindex directive and a robots.txt. This protects nobody who has the URL; it stops the URL becoming public by accident, which is the likeliest way obscurity fails.
  • Corrected CLAUDE.md, README.md and SPEC.md, which all still described a Google Sheet as the interface and forbade the web front end that now exists.

v0.4.0

21 September 2026
  • Teamtailor added as a sixth adapter. Its career sites publish an open JSON feed carrying a full schema.org JobPosting — real publication dates and structured addresses. Previously written off as closed without being tested, which was wrong. Unlocks IAG Cargo and a large slice of UK and Nordic employers.
  • Recency now uses the employer's publication date where the source provides a trustworthy one. Greenhouse exposes only updated_at, which moves whenever anyone edits a posting, so those roles still fall back to first-seen. This is why the hot, 48-hour and 7-day counts previously returned identical numbers.
  • Workday's relative dates parsed. "Posted 3 Days Ago" becomes an approximate timestamp, which is far better than nothing for a 24-hour window.
  • Seniority classified into three tiers — exec, director, mid-senior — rather than a single accept-or-reject rule. Title inflation runs opposite to company size, so one threshold could never fit both a 30-person startup and Deliveroo. Verified against 39 sample titles.
  • Employer list expanded to 211, adding adjacent businesses and startups above roughly ten people, with a new startup size bucket.
  • The goose gained three frames — wing flap, look up, foot stamp — and now performs one of fifteen weighted acts every seven seconds.
  • Hard offset shadows, bevelled surfaces, a faint tiled background and press states that push buttons into their own shadow.
  • This page.
Known gaps: British Airways publishes no machine-readable feed and disallows its search endpoint in robots.txt, so it cannot be covered. SuccessFactors, Taleo and iCIMS remain unsupported, which is most of the enterprise bucket.

v0.3.0

20 September 2026
  • Geography tightened to the UK, or remote within GMT ±3. A Berlin office role is neither. An impostor guard rejects London Ontario, Birmingham Alabama and Manchester New Hampshire before the UK pattern can match them.
  • Hot filter for roles under 24 hours old, with its own colour so it reads as a distinct urgency level rather than a gradient.
  • Live countdown to the next collection, to the second, on a 24-block segmented meter. It says "due", never promises — GitHub queues scheduled workflows and runs them late under load.
  • Mobile filters collapsed behind a disclosure. They had been a sticky block occupying over half the viewport; now 86 pixels.
  • Mobile Safari: 16px inputs to stop focus-zoom, safe-area insets, tinted toolbars, dvh units, and 44px touch targets.
  • Goose and wordmark put on a shared pixel grid.

v0.2.0

20 September 2026
  • The web interface. Segmented by employer size, faceted filtering, shortlist and dismiss, staleness detection. One file, no framework, no build step.
  • Deployed on Cloudflare Pages from a private repository, rebuilding on every commit. GitHub Pro proved unnecessary — Cloudflare serves private repos free.
  • State tracking. Each run merges into the previous feed so first_seen survives; roles missing twice are treated as closed.
  • Scheduled collection every two hours via GitHub Actions, committing only on change.
  • Pixel goose and art-deco wordmark, generated as SVG from a single Python file.
  • Found /site in the stock Python .gitignore, which had been silently excluding the entire deployed application.

v0.1.0

19 September 2026
  • First working collector. Greenhouse, Lever, Ashby and SmartRecruiters, all keyless.
  • Board-token discovery. Real tokens are untidy — ShipBob is shipbobinc, Neuron Mobility is neuron — so the prober generates variants. Greenhouse also runs a separate EU API host that the first pass never tried.
  • Workday adapter, hand-configured per employer from a careers URL, since tenant and site names cannot be guessed.
  • Scope set to transport, logistics, mobility and aviation. Previous employers excluded by design.
First pass resolved 25% of employers. The causes were guessable token shapes and the unqueried EU Greenhouse host, not absent coverage.
Versioning is major.minor.patch, bumped by hand. Still 0.x: the data contract is not stable and the matching rules are being actively tuned.
