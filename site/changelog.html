Version history

7 October 2026 current

v0.4.6
  • Every role was published twice. 958 roles in scope were really 480. One duplicated line; every figure on the feed was double.
  • Correction: it was fixed on 21 September and undone thirteen minutes later by an unrelated header commit written over a stale copy of the file, which took the location reason with it. Reported fixed again on 5 October with nothing reaching the repository.
  • A failed push no longer discards a collection. It now retries three times, reconciling last-write-wins rather than rebasing — incident.
  • The header was broken on a phone. Its fixed 64px height was never released at the width where the bar wraps, so the second row painted over the page.
  • Tabs scroll on a phone, 40px targets, current page centred. Figures sit two-up. Nothing widens the page, checked from 320 to 1280px on all five pages.
  • The match line names the location again instead of falling back to "Location accepted".
  • The status page separates an open incident from history and now carries two.
  • Correction: the 5 October outage was estimated at two hours while it was still running. It was 5h 55m.

5 October 2026

v0.4.4 → v0.4.5
  • Status and outages page added. Status and uptime are computed live from the GitHub Actions API, not typed in, so they cannot drift from the truth.
  • First incident recorded. GitHub stopped allocating runners for nearly six hours. No application fault and no data loss.
  • Updates run newest first, and resolution criteria are written down before they are wanted — which is what stops a status page flattering itself.
  • The header stopped moving between pages. Four stale rules had each survived an earlier layout and quietly won: a duplicate .bar-wrap, a leftover align-self, a second .alpha, and the feed's own lockup off the shared art grid.
  • Five dead rules deleted for a masthead and a tagline that no longer exist in the markup.
  • The banner states UTC. It had shown the viewer's own timezone against a log written entirely in UTC.
  • Runner pinned to ubuntu-24.04 ahead of the Ubuntu 26 migration on 19 October.
  • Correction: moving the schedule to :37 was meant to shorten GitHub's queue delay. Measured over a fortnight it has not — runs still start 14 to 22 minutes late.

21 September 2026

v0.4.0 → v0.4.3
  • Teamtailor added as a sixth adapter. Eight employers including GXO, Maersk, Geodis and Europcar. It alone moved enterprise reachability from 15% to 22%.
  • Discovery re-run across 211 employers: 62 resolved (29%, from 22%), 5,541 roles assessed, 564 in scope, 7 matched.
  • SmartRecruiters paging fixed. Sixt, Delivery Hero and Grab were each capped at exactly 100 postings. Total supply rose from 3,698 to about 5,500.
  • Recency now uses the employer's publication date where the source provides a trustworthy one. Greenhouse's updated_at is not one, which is why the 24h, 48h and 7d counts had been identical.
  • Seniority split into exec, director and mid-senior. Title exclusions extended to finance, legal, payroll, procurement, talent and HR operations.
  • Two silent data defects fixed: a duplicated line published every role twice, and the geography verdict was computed then discarded.
  • Coverage page added — all 211 employers, reachable or not, by size band and system. Product brief rewritten as a PRD with a stop decision.
  • Interface: shared lockup and a fixed navigation bar across all pages, one control height throughout, filters on one row, stats as a strip, a wider tonal range with a fourth accent hue, crawler exclusion and scheme-checked links.
  • The feed now says what the last collection changed — new and closed counts, or “no change last run”, because a run that changes nothing is evidence the market is still, not that the collector is broken.
  • Tagline replaced. The two-line sector list truncated at every width and said nothing the page did not already show.
  • Collection moved from :00 to :37 after firing 11–17 minutes late on 14 of 14 runs.
Reasoning for these changes is in the product brief. This page records what changed, not why.

20 September 2026

v0.2.0 → v0.3.0
  • The web interface — segmented by employer size, faceted filters, shortlist, dismiss. One file, no framework, no build step.
  • Deployed on Cloudflare Pages from a private repository. GitHub Pro proved unnecessary.
  • Scheduled collection every two hours via GitHub Actions, with a state merge so first_seen survives and roles missing twice are treated as closed.
  • Geography restricted to the UK or remote within GMT ±3, with an impostor guard for London Ontario and similar.
  • Hot filter for roles under 24 hours old; live countdown to the next collection.
  • Mobile Safari: filters collapsed from over half the viewport to 86px, 16px inputs, safe-area insets, dvh units.
  • /site found in the stock Python .gitignore, silently excluding the entire application.

19 September 2026

v0.1.0
  • First collector — Greenhouse, Lever, Ashby and SmartRecruiters, all keyless.
  • Board-token discovery by variant generation; Greenhouse's separate EU host added. First pass resolved 25% of employers.
  • Workday adapter, hand-configured per employer from a careers URL.
  • British Airways assessed and recorded as uncovered: no machine-readable feed, and robots.txt disallows the search path.
Versioning is major.minor.patch, bumped by hand. Still 0.x, and it will stay there: the product brief records a decision to stop developing this as a job-search tool.
